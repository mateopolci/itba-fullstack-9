## Descripción

Mueblería Hermanos Jota es un sitio web para una mueblería artesanal con más de 30 años de tradición. Permite conocer la historia del negocio, explorar un catálogo de muebles, buscar productos y consultar el detalle de cada uno.

Además, los usuarios pueden agregar productos al carrito de compras, visualizar los artículos seleccionados, vaciar el carrito y confirmar la compra. La información del carrito se conserva en el navegador mediante `localStorage`. El sitio también cuenta con una sección de contacto para realizar consultas.

## Tecnologías utilizadas
